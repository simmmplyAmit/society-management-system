User Roles
1. Society Admin
2. Society Secretary
2. Society Treasurer
2. Resident Owners
3. Resident Tanents


Core Workflows
1. Society Onboarding
	1. A society will be onboarded and an admin login will be created by the product team.
	2. Admin then will fill in society details like Number of wings, floors, flats etc.
	3. Admin will then create users and map them to respective flats.
	4. Admin will also create society treasurer and secratory

2. Flat - Resident Mapping
	1. A flat can have multiple residents and more than 1 person can be marked as owners.
	2. A flat can have separate owners and tenants.
	3. A person can be owner of multiple flats.
	4. Need to maintain a tenant management system to record the dates of occupancy of each tenants.

3. Maintenance system
	1. Society admin will tag a maintenance amount for each flat. 
	2. Each entry will have a start and end month for which the maintenance is appliable.
	
4. Maintenance alerts and payment capture
	1. Each month maintenance alert if not already paid will be generated by 1st of next month.
	2. Maintenance can be directly paid into society bank account using the UPI Id.
	3. An overnight process will verify all the maintainance paid. To be finalized later.
	
5. Society Expenses
	1. Society Treasurer adds society expenses and visible to admin, secretary and treasurer
	
6. Tenant Management System.
	1. Record all tenants for each flat and clearly mark their start and end dates.

7. Secretary and Treasurer roles
	1. To be decided later
